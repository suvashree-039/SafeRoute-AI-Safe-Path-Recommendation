About SafePath

SafePath is an intelligent safe route recommendation system designed to help users identify safer routes by combining road-network information, safety infrastructure, crime context and machine learning.

🎯 Our Objective

The main objective of SafePath is to recommend routes that provide a better balance between travel distance and road safety.

Instead of considering only the shortest route, SafePath evaluates safety-related information associated with road segments.

🚦 How SafePath Works

  • 📍 Uses road-network data to represent available routes.
  • 🏥 Considers nearby hospitals and emergency facilities.
  • 👮 Considers nearby police stations.
  • 📹 Considers CCTV surveillance coverage.
  • 💡 Considers street-light availability.
  • 🛣️ Calculates safety scores for road segments.
  • 🤖 Uses a Random Forest classification model for safety-category prediction.

🗺️ Safe Route Recommendation

SafePath uses a routing graph created from the road network. Each road segment contains safety information that can influence route selection.

The system attempts to find a route that provides a practical balance between road distance and safety rather than simply selecting the shortest road.

🤖 Machine Learning

A Random Forest classifier is used to classify road segments into four safety categories:

  • 🟢 Very Safe
  • 🟢 Safe
  • 🟠 Moderate
  • 🔴 High Risk
